# Reflect Open 功能迁移

本文记录 `/Users/raoqu/research/reflect-open` 到墨笺的功能映射。迁移目标是把
Reflect 的用户能力完整落到现有 Go、SQLite、React/Vinext 架构中，同时保留墨笺
已有的多笔记本、目录导入导出和静态发布能力。

## 1. 架构映射

| Reflect Open | 墨笺中的实现 |
| --- | --- |
| Tauri 命令和本地文件系统 | Go HTTP API |
| Markdown 文件图谱 | SQLite `documents` 内容与可重建索引 |
| Meowdown 编辑器 | `app/reflect/reflect-editor.tsx` |
| Rust SQLite 索引 | Go SQLite 数据库与后续 FTS5 索引 |
| React Router 路由 | `WorkspaceView` 和工作区历史栈 |
| Graph provider | 当前笔记本及其扁平文档投影 |
| OS Keychain | Go 服务通过系统钥匙串保存 BYOK 密钥，数据库仅保留掩码 |
| Tauri 文件监听 | Web 自动保存、修订号、乐观锁与外部写入轮询/聚焦刷新 |
| Git/iCloud 同步 | 独立 Git 投影仓库、HTTPS/SSH/本地远端和 Markdown 冲突解决；Web 架构不直接接入 iCloud |
| Chrome 扩展 native messaging | 本地 Bearer Token 捕获 API、扩展离线队列与重试 |
| `reflect://` 与 Tauri 多窗口 | 可复制的 Web 深链、PWA 启动快捷方式和浏览器独立笔记窗口 |
| macOS/iOS 原生壳 | 可安装 PWA、离线应用壳、移动安全区与抽屉导航 |

## 3. 当前迁移批次

首批已经完成“写作—关联—查找—执行”的主链路：

1. Meowdown 编辑和格式化；
2. 每日笔记与普通笔记创建；
3. Wiki 链接、标签和反向链接；
4. 全局搜索与命令；
5. Reflect 圆形任务汇总及写回；
6. 固定、私密、废纸篓元数据；
7. 自动保存和编辑器偏好设置。

第二批已经补齐数据正确性能力：逐文档 API、乐观锁与冲突处理、frontmatter
保真、Markdown 往返保护、重命名链接重写、FTS5 搜索和完整废纸篓。

第三批已经迁入 AI 主路径：选区流式改写采用 Meowdown 暂存替换，只有用户接受后
才写入笔记；Chat 支持 OpenAI、Anthropic、Google Gemini、OpenRouter BYOK、系统
钥匙串、持久对话与知识库来源。所有出站入口在 Go 服务中再次读取当前笔记隐私
状态，不能仅靠前端放行。

第四批已经完成任务高级操作、模板、多知识库、通用附件、CLI、音频备忘、浏览器
捕获、Git 同步、资源 AI 描述、Wiki 悬浮预览、Web 深链和 PWA 平台适配。Git 同步
使用系统 Git 进程实现，而非 Reflect 的 Rust Git 层；凭据仍只进入系统钥匙串和
进程环境，不写入仓库或数据库明文。

当前尚不能称为逐项完整迁移：本机语义模型依赖未获安装授权；Apple Calendar 与
Contacts 依赖 EventKit/CNContactStore 原生权限宿主，Go/Web 运行形态没有等价接口。
此外 AI Chat 已实现本地检索接地，但还不是 Reflect 规划中的模型原生多轮工具循环。
